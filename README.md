# lost-wallet-finder

A cross-platform wallet recovery tool (Web + Mobile) focused on local-only keystore storage and EVM-chain recovery (Ethereum + Polygon mainnet).

This repo contains a scaffold for the wallet recovery MVP: shared core library, web app (React + Vite), and mobile app (Expo + React Native), along with tests and docs.

SECURITY NOTICE: This project handles private keys and seed phrases. Keep keys offline and never share them. This scaffold is for educational and legitimate recovery use only. Do not use it to access wallets you do not own. Use mainnet carefully — transactions cost real funds.
